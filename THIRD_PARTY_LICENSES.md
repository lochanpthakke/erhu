# Android third-party licence inventory

Audit date: 10 November 2026. Android source snapshot: `69be688c19cd06987e77fa0bf9be4632fbcb986b` (1.0.17, code 18). This licensing-only branch does not change dependencies.

## Status and method

**This is a resolved-component inventory and evidence record, not a proprietary-distribution clearance.**

A temporary Gradle task resolved the actual app release/debug runtime and compile graphs once successfully, including transitive components. It added no permanent plugin or Gradle configuration. The first artifact enumeration attempt failed on AGP variant ambiguity; the successful report uses the resolved component graph, official publisher POMs and locally available binary inspection rather than guessing project variants. Counts: **282 distinct group/artifact/version coordinates**; release runtime 243, debug runtime 249, release compile 157, debug compile 163. These counts include platform/BOM/Kotlin metadata nodes and differing compile/runtime versions; they are not APK library counts.

Publisher POM licence declarations were inspected for every coordinate. Seven missing declarations were followed through parent POMs or the published source (javax.inject). Cached JAR/AAR contents were inspected for 212 coordinates, including nested classes.jar. The remaining 70 had no cached binary at inspection time, many being metadata/platform coordinates; **POM-only evidence is not a claim that their full binary notices were inspected**. Six distinct embedded legal texts were preserved verbatim in content in [the notice collection](LICENSES/THIRD-PARTY-NOTICES.txt). SHA-256 identifiers in that collection refer to the extracted original UTF-8 texts, before document framing.

The inventory does not cover npm administration tools, JDK/Gradle/AGP build-tool internals or a complete MediaPipe native-component SBOM. Those are not silently declared application-owned. No manually bundled application JAR/AAR/model/native binary/font was found in tracked source; `gradle-wrapper.jar` is build infrastructure with its existing Apache notices preserved. The VYBE model is a separate release download, described below.

## Obligation keys

- **A — Apache-2.0:** preserve the licence and applicable copyright/attribution notices; include any supplied NOTICE content; mark modifications when applicable. No general application-source publication requirement is inferred. Patent/trademark clauses remain applicable. [Official text](https://www.apache.org/licenses/LICENSE-2.0).
- **B — BSD-3-Clause:** retain the copyright, conditions and disclaimer with source/binary redistribution; do not imply endorsement. No general application-source publication requirement. [Licence text](https://opensource.org/license/bsd-3-clause).
- **M — MIT:** retain the copyright and permission notice in copies/substantial portions. No general application-source publication requirement. [Licence text](https://opensource.org/license/mit).
- **L — LGPL-2.1-or-later:** see the specific jaudiotagger assessment below; provide the applicable notice/licence and corresponding library source plus a compliant replacement/relinking route, with permitted modification and reverse engineering for debugging such modifications. **Not cleared by a keep rule or a source URL alone.** [Preserved text](LICENSES/LGPL-2.1-or-later.txt).
- **P — MPL-2.0:** the covered public-suffix dataset retains its source-form rights, required notices and source availability. The larger application may have separate terms, but may not override those rights. Identify the corresponding source used for the bundled generated data. [Preserved text](LICENSES/MPL-2.0.txt).
- **S — Android SDK terms:** publisher declares the Android Software Development Kit License, not Apache. Assess the applicable SDK/component redistribution and platform conditions. No open-source source grant is inferred from this label. [Official terms](https://developer.android.com/studio/terms.html).
- **C — GPLv2 with Classpath exception / MIT declarations:** checker-compat-qual's POM lists both. Do not misclassify it as unconditional GPL application copyleft or assume a choice without examining the applicable upstream grant. Preserve the library's terms and any source obligations for redistributed library modifications. [Publisher metadata](https://repo.maven.apache.org/maven2/org/checkerframework/checker-compat-qual/2.5.3/checker-compat-qual-2.5.3.pom).
- **N — native transitive components:** AndroidX and especially MediaPipe AARs contain native binaries whose complete constituent licence/NOTICE bill of materials is not supplied by the module-level Apache declaration. Obtain the exact release's supplier notices/SBOM before proprietary distribution. This is a clearance gap, not evidence that those binaries are GPL.
- **U — unresolved:** no licence conclusion may be drawn until upstream evidence is supplied.

A copyright value of **not explicit** means the inspected published metadata/binary did not provide a reliable component-specific copyright holder. No holder/year was invented from a group name. Obtain and preserve the upstream notice/source headers before distributing where required. All such rows remain attribution-verification items even when the publisher's licence declaration is verified. Complete licence texts already present in a JAR are not proof that no other NOTICE is required.
